# Powiedz na P!

Prosta polska gra towarzyska na telefon: opisz wyświetlane hasło, używając słów zaczynających się na literę **P**.

Gra działa w przeglądarce na iPhonie i Androidzie. Ma 341 haseł, trzy poziomy trudności, minutnik, podpowiedzi i możliwość udostępnienia linku. Po pierwszym uruchomieniu może działać offline.

## Uruchomienie

Po włączeniu GitHub Pages w ustawieniach tego repozytorium: 

https://sobierajskimat-hash.github.io/Gra-na-P/

### Włączenie GitHub Pages

**Settings → Pages → Build and deployment → Deploy from a branch → main → /(root) → Save.**

Projekt jest statyczny: nie przechowuje danych użytkowników i nie wymaga własnego serwera.
